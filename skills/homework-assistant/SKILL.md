# 作业协助与最终检查

## 确认任务现场

对分易（duifene.com）作业必须先读取 [对分易专用流程](references/duifene.md)，按现场结构验证后使用。

在Codex Windows中首次使用、缺少浏览器能力或用户要求自动配置依赖时，先读取 [Codex自动准备](references/codex-setup.md)，使用附带脚本检查、安装依赖和注册MCP。已有可用连接则直接复用。

在WorkBuddy Windows中使用时，先读取 [WorkBuddy自动准备](references/workbuddy-setup.md)，使用对应配置脚本，不修改Codex配置，也不假定WorkBuddy可直接加载Codex插件manifest。

- 新电脑先检查实际可用工具和技能。附带脚本可在授权范围内安装必要运行时和浏览器、准备MCP；不会自动登录账号，不假定旧电脑配置已迁移。

- 从用户提供的题目、文件或已登录页面确认课程、作业名称、题量、题型、截止时间与提交要求。
- 在线页面使用可用的浏览器工具；已安装web-access时遵循其联网流程，否则按本技能附带的对分易和Codex准备说明操作，不要求另外安装该技能。Markdown交付无需额外文档插件；其他格式按实际需求检查工具。
- 用户已明确的范围和授权持续有效，不重复询问。默认完成解答、填写、保存、答案整理，将最终提交留给用户；用户明确要求代为提交时按其授权执行。
- 启动限时练习前确认是否到时自动提交。尽量先通过平台正常提供的题目预览获取内容，再启动计时；无法预览时，在进入后预留充足检查及用户提交时间。不能承诺暂停或关闭页面会停止计时。

## 解答与整理

- 完整读取题干、共用材料、图片、公式及全部选项，确认单选、多选、判断等题型。
- 按题目／字段的稳定 ID 关联题干、选项、作答顺序；随机题号、题库排序和复查页题号可能不同，不能按数组下标直接配答案。
- 先推导再填写；计算、文法分析、程序题可用可复现计算核对。图片题必须查看实际图示。检查否定词、限定条件、空串、边界条件与多选完整性。
- 对不确定或题干歧义重新审题、计算或查阅可靠材料。仍无法确定时，在交付中指出具体题目和疑点，不把猜测称为确定答案。
- 整理一份题目、选项、答案与必要解析的文件。记录本次题号和稳定 ID；标明答案是自行推导、实际保存还是平台公布，不能混用。使用用户指定目录，否则存放在当前工作区并给出绝对路径链接。

## 填写和保存

- 每题核对当前显示题干／ID与目标题一致，再按实际选项文字填写。多选题检查完整选项集合，避免漏选或误取消。
- 对异步自动保存，确认当前保存完成再切题。核对每次请求的目标 ID、完整答案及业务响应，不能只看 HTTP 200。
- 完成后用平台正常提供的服务器回读或保存后详情，逐题比较计划答案与实际保存答案。不能只凭页面选中、答题卡数量或最后一次“保存成功”宣称全部保存已核实。
- 不擅自提交以获得复查页面，不绕过尚未开放的练习或未公布答案的访问限制。若没有安全的服务器回读途径，明确指出只能验证到哪一层，不能声称持久化已全部核实。

## 最后检查（交付前必须执行）

1. **内容检查**：题目、共用材料和选项是否完整；题型、否定条件、多选集合与推导是否正确；疑点是否已注明。
2. **对应检查**：逐题核对稳定 ID、题干、计划答案和当前实际答案；作答页与答案文件必须一致。
3. **保存检查**：逐题验证业务保存响应与服务器回读值。发现差异，先修正再重新验证；无法验证时报告具体缺口。
4. **文件检查**：回读生成文件，确认题量、题号、答案和解析完整，链接可用。
5. **提交状态检查**：用户自行提交时保留未提交状态，告知剩余时间和自动提交规则；明确授权代为提交时，提交后核实提交时间、已完成状态和平台成绩是否公布。

最终只报告实际完成和验证过的结果，给出答案文件、提交状态及具体待办。操作完成与答案正确性分别说明；成绩未公布时不声称满分。

发生答案差异时，保留不含认证信息的逐题比较记录和可用请求证据。未查实前，不断言是平台故障、保存竞态或用户修改。
