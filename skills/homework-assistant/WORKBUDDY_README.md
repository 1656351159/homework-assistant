# WorkBuddy 作业助手安装说明

在WorkBuddy“技能→添加技能→上传技能”中导入此ZIP并启用。若界面名称不同，按实际本地技能导入入口操作。

首次输入：

> 使用作业助手。授权自动准备所需Node.js、Chrome、Playwright MCP并配置WorkBuddy连接器。打开对分易让我登录，完成我指定的作业并逐题检查，整理题目答案，提交留给我。

技能会读取`references/workbuddy-setup.md`，准备依赖并检查浏览器连接。MCP配置需要现场确认路径；能确认时自动备份合并，无法确认时生成JSON供自定义连接器添加。首次导入、系统授权或连接器启用可能仍需一次用户操作。

此包不含登录信息，不需要复制旧电脑配置。独立浏览器登录一次后可在本机保留；验证码和最终提交由用户操作。

保留本目录完整路径；注册后不要随意移动目录，否则MCP启动脚本路径需要重新配置。此版本适配Windows；其他系统需按其运行时和客户端配置重新调整。
